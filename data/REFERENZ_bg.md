# Справочник с функции – LibreOffice Calc Formula Helper

Всички функции, налични в програмата, със синтаксис, параметри и примери.

---

## Раздел 1 – Основни функции

### Аритметични оператори

| Оператор | Значение | Пример | Резултат |
|----------|----------|--------|---------|
| `+` | Събиране | `=A1+B1` | Сума на две клетки |
| `-` | Изваждане | `=A1-B1` | Разлика |
| `*` | Умножение | `=A1*B1` | Произведение |
| `/` | Деление | `=A1/B1` | Частно |
| `^` | Степенуване | `=A1^2` | A1 на квадрат |

---

### СУМА
**Синтаксис:** `=СУМА(диапазон)`

Събира всички числа в диапазон от клетки.

| Параметър | Описание |
|-----------|---------|
| `диапазон` | напр. `A1:A10` |

```
=СУМА(A1:A10)
```

---

### СРЕДНО
**Синтаксис:** `=СРЕДНО(диапазон)`

Изчислява средната стойност на всички числа в диапазона.

```
=СРЕДНО(A1:A10)
```

---

### МИН
**Синтаксис:** `=МИН(диапазон)`

Връща най-малката стойност в диапазона.

```
=МИН(A1:A10)
```

---

### МАКС
**Синтаксис:** `=МАКС(диапазон)`

Връща най-голямата стойност в диапазона.

```
=МАКС(A1:A10)
```

---

### БРОЙ
**Синтаксис:** `=БРОЙ(диапазон)`

Брои всички клетки с **числови стойности** в диапазона.

```
=БРОЙ(A1:A10)
```

---

### БРОЙ2
**Синтаксис:** `=БРОЙ2(диапазон)`

Брои всички **непразни** клетки (числа и текст).

```
=БРОЙ2(A1:A10)
```

---

### МЕДИАНА
**Синтаксис:** `=МЕДИАНА(диапазон)`

Връща медианата на сортирания списък със стойности (средната стойност).

```
=МЕДИАНА(A1:A10)
```

---

### СУМАПРОИЗВ
**Синтаксис:** `=СУМАПРОИЗВ(диапазон1; диапазон2)`

Умножава елементите на два диапазона и събира резултатите.

| Параметър | Описание |
|-----------|---------|
| `диапазон1` | Първи диапазон |
| `диапазон2` | Втори диапазон (еднакъв размер) |

```
=СУМАПРОИЗВ(A1:A10; B1:B10)
```

---

## Раздел 2 – Разширени функции

### АКО
**Синтаксис:** `=АКО(условие; тогава; иначе)`

Връща една от две стойности в зависимост от това дали условието е вярно или невярно.

| Параметър | Описание |
|-----------|---------|
| `условие` | напр. `A1>0` |
| `тогава` | Стойност ако е вярно |
| `иначе` | Стойност ако е невярно |

```
=АКО(A1>0; "ОК"; "Грешка")
```

---

### И
**Синтаксис:** `=И(условие1; условие2)`

Връща ИСТИНА ако **всички** условия са изпълнени.

```
=И(A1>0; B1>0)
```

---

### ИЛИ
**Синтаксис:** `=ИЛИ(условие1; условие2)`

Връща ИСТИНА ако **поне едно** условие е изпълнено.

```
=ИЛИ(A1>0; B1>0)
```

---

### НЕ
**Синтаксис:** `=НЕ(условие)`

Обръща логическа стойност: ИСТИНА → ЛЪЖА, ЛЪЖА → ИСТИНА.

```
=НЕ(A1>0)
```

---

### СУМААКО
**Синтаксис:** `=СУМААКО(диапазон; критерий; сума_диапазон)`

Събира стойности, които отговарят на критерий.

| Параметър | Описание |
|-----------|---------|
| `диапазон` | Диапазон, който се проверява |
| `критерий` | напр. `">10"` или `"Да"` |
| `сума_диапазон` | Диапазон, който се събира |

```
=СУМААКО(A1:A10; ">10"; B1:B10)
```

---

### БРОЙАКО
**Синтаксис:** `=БРОЙАКО(диапазон; критерий)`

Брои клетки, които отговарят на критерий.

```
=БРОЙАКО(A1:A10; "Да")
```

---

### СРЕДНОАКО
**Синтаксис:** `=СРЕДНОАКО(диапазон; критерий; средно_диапазон)`

Изчислява средната стойност на стойностите, отговарящи на критерий.

```
=СРЕДНОАКО(A1:A10; ">0"; B1:B10)
```

---

### СУМААКОС
**Синтаксис:** `=СУМААКОС(сума_диапазон; критерии_диапазон; критерий)`

Събира стойности, отговарящи на **множество** критерии.

| Параметър | Описание |
|-----------|---------|
| `сума_диапазон` | Диапазон, който се събира |
| `критерии_диапазон` | Диапазон, който се проверява |
| `критерий` | Условие напр. `">10"` |

```
=СУМААКОС(A1:A10; B1:B10; ">10")
```

---

### СТОТКЛОН
**Синтаксис:** `=СТОТКЛОН(диапазон)`

Изчислява стандартното отклонение (разпръснатост на стойностите).

```
=СТОТКЛОН(A1:A10)
```

---

### ДИСП
**Синтаксис:** `=ДИСП(диапазон)`

Изчислява дисперсията (квадратична разпръснатост).

```
=ДИСП(A1:A10)
```

---

### БРОЙПРАЗНИ
**Синтаксис:** `=БРОЙПРАЗНИ(диапазон)`

Брои всички **празни** клетки в диапазона.

```
=БРОЙПРАЗНИ(A1:A10)
```

---

### ГОЛЯМ
**Синтаксис:** `=ГОЛЯМ(диапазон; k)`

Връща k-тата най-голяма стойност в диапазона.

| Параметър | Описание |
|-----------|---------|
| `диапазон` | Числов диапазон |
| `k` | Ранг (1 = най-голям, 2 = втори по големина, …) |

```
=ГОЛЯМ(A1:A10; 2)
```

---

## Раздел 3 – Дата и текст

### ДНЕС
**Синтаксис:** `=ДНЕС()`

Връща текущата дата. Актуализира се при всяко отваряне на файла.

```
=ДНЕС()
```

---

### СЕГА
**Синтаксис:** `=СЕГА()`

Връща текущата дата **с час**.

```
=СЕГА()
```

---

### ГОДИНА
**Синтаксис:** `=ГОДИНА(дата)`

Извлича годината от дата.

```
=ГОДИНА(A1)
```

---

### МЕСЕЦ
**Синтаксис:** `=МЕСЕЦ(дата)`

Извлича месеца (1–12) от дата.

```
=МЕСЕЦ(A1)
```

---

### ДЕН
**Синтаксис:** `=ДЕН(дата)`

Извлича деня (1–31) от дата.

```
=ДЕН(A1)
```

---

### ДАТА
**Синтаксис:** `=ДАТА(година; месец; ден)`

Създава дата от отделни стойности.

```
=ДАТА(2025; 1; 1)
```

---

### DATEDIF
**Синтаксис:** `=DATEDIF(начална_дата; крайна_дата; единица)`

Изчислява разликата между две дати.

| Единица | Значение |
|---------|---------|
| `"D"` | Дни |
| `"M"` | Месеци |
| `"Y"` | Години |

```
=DATEDIF(A1; B1; "D")
```

> **Забележка:** DATEDIF е недокументирана функция – работи в LibreOffice и Excel, но не се появява в автодовършването.

---

### ДЕННАСЕДМИЦАТА
**Синтаксис:** `=ДЕННАСЕДМИЦАТА(дата; тип)`

Връща деня от седмицата като число.

| Тип | Значение |
|-----|---------|
| `2` | 1=Пон, 2=Вт, … 7=Нед (препоръчително) |
| `1` | 1=Нед, 2=Пон, … 7=Съб |

```
=ДЕННАСЕДМИЦАТА(A1; 2)
```

---

### CONCATENATE
**Синтаксис:** `=CONCATENATE(текст1; текст2; …)`

Обединява няколко текста в един.

```
=CONCATENATE(A1; " "; B1)
```

---

### ДЪЛЖИНА
**Синтаксис:** `=ДЪЛЖИНА(текст)`

Връща броя на знаците в текст.

```
=ДЪЛЖИНА(A1)
```

---

### ЛЯВО
**Синтаксис:** `=ЛЯВО(текст; брой)`

Връща първите n знака от текст.

```
=ЛЯВО(A1; 5)
```

---

### ДЯСНО
**Синтаксис:** `=ДЯСНО(текст; брой)`

Връща последните n знака от текст.

```
=ДЯСНО(A1; 5)
```

---

### СРЕДНА
**Синтаксис:** `=СРЕДНА(текст; начална_позиция; брой)`

Връща подниз от текст.

| Параметър | Описание |
|-----------|---------|
| `текст` | Изходен текст |
| `начална_позиция` | От кой знак (1 = първи) |
| `брой` | Колко знака |

```
=СРЕДНА(A1; 1; 5)
```

---

### ГЛАВНИ
**Синтаксис:** `=ГЛАВНИ(текст)`

Преобразува всички букви в главни.

```
=ГЛАВНИ(A1)
```

---

### МАЛКИ
**Синтаксис:** `=МАЛКИ(текст)`

Преобразува всички букви в малки.

```
=МАЛКИ(A1)
```

---

### ИЗЧИСТИ
**Синтаксис:** `=ИЗЧИСТИ(текст)`

Премахва излишните интервали (водещи, следващи и двойни).

```
=ИЗЧИСТИ(A1)
```

## Раздел 4 – Търсене и закръгляване

### VLOOKUP
**Синтаксис:** `=VLOOKUP(търсена_стойност; таблица; индекс_на_колона; съвпадение)`

Търси стойност в **първата колона** на таблица и връща стойността от друга колона.

| Параметър | Описание |
|-----------|---------|
| `търсена_стойност` | Търсена стойност, напр. `A1` |
| `таблица` | Диапазон за търсене, напр. `B1:D10` |
| `индекс_на_колона` | Номер на колоната за връщане (1 = първа колона) |
| `съвпадение` | `0` = точно, `1` = приблизително |

```
=VLOOKUP(A1; B1:D10; 2; 0)
```

---

### HLOOKUP
**Синтаксис:** `=HLOOKUP(търсена_стойност; таблица; индекс_на_ред; съвпадение)`

Като VLOOKUP, но търси в **първия ред** (хоризонтално).

```
=HLOOKUP(A1; B1:D10; 2; 0)
```

---

### ИНДЕКС
**Синтаксис:** `=ИНДЕКС(диапазон; ред; колона)`

Връща стойността на определена позиция в диапазона.

| Параметър | Описание |
|-----------|---------|
| `диапазон` | Диапазон за търсене |
| `ред` | Номер на ред |
| `колона` | Номер на колона (по подразбиране: 1) |

```
=ИНДЕКС(B1:B10; 3; 1)
```

---

### СЪВПАДЕНИЕ
**Синтаксис:** `=СЪВПАДЕНИЕ(търсена_стойност; диапазон_за_търсене; тип_съвпадение)`

Връща **позицията** на стойност в диапазон.

| Тип съвпадение | Значение |
|----------------|---------|
| `0` | Точно съвпадение |
| `1` | Най-малкото, по-голямо или равно |
| `-1` | Най-голямото, по-малко или равно |

```
=СЪВПАДЕНИЕ(A1; A1:A10; 0)
```

---

### ИНДЕКС + СЪВПАДЕНИЕ
**Синтаксис:** `=ИНДЕКС(резултатен_диапазон; СЪВПАДЕНИЕ(търсена_стойност; диапазон_за_търсене; 0))`

По-гъвкава алтернатива на VLOOKUP – може да търси в **произволна посока**.

| Параметър | Описание |
|-----------|---------|
| `резултатен_диапазон` | Колона с върнати стойности |
| `търсена_стойност` | Търсена стойност |
| `диапазон_за_търсене` | Колона, в която се търси |

```
=ИНДЕКС(B1:B10; СЪВПАДЕНИЕ(A1; A1:A10; 0))
```

> **Предимство пред VLOOKUP:** Колоната за търсене не е задължително да е първата колона. Стабилна и при вмъкване/изтриване на колони.

---

### ЗАКРЪГЛИ
**Синтаксис:** `=ЗАКРЪГЛИ(число; десетични_знаци)`

Закръгля до посочения брой десетични знаци.

| Десетични знаци | Пример |
|----------------|--------|
| `2` | 3,14159 → 3,14 |
| `0` | 3,7 → 4 |
| `-1` | 34 → 30 |

```
=ЗАКРЪГЛИ(A1; 2)
```

---

### ЗАКРЪГЛИНАГОРЕ
**Синтаксис:** `=ЗАКРЪГЛИНАГОРЕ(число; десетични_знаци)`

Винаги закръгля **нагоре** (от нулата).

```
=ЗАКРЪГЛИНАГОРЕ(A1; 2)
```

---

### ЗАКРЪГЛИНАДОЛУ
**Синтаксис:** `=ЗАКРЪГЛИНАДОЛУ(число; десетични_знаци)`

Винаги закръгля **надолу** (към нулата).

```
=ЗАКРЪГЛИНАДОЛУ(A1; 2)
```

---

### ЦЯЛО
**Синтаксис:** `=ЦЯЛО(число)`

Закръгля надолу до най-близкото цяло число (включително за отрицателни числа).

```
=ЦЯЛО(A1)
```

---

### ОТРЕЖИ
**Синтаксис:** `=ОТРЕЖИ(число; десетични_знаци)`

Отрязва десетичните знаци **без** закръгляне.

```
=ОТРЕЖИ(A1; 2)
```

---

### АБС
**Синтаксис:** `=АБС(число)`

Връща **абсолютната стойност** (винаги положителна).

```
=АБС(A1)
```

---

### ОСТАТЪК
**Синтаксис:** `=ОСТАТЪК(число; делител)`

Връща **остатъка** от деление.

```
=ОСТАТЪК(A1; 3)
```
> Пример: `=ОСТАТЪК(10; 3)` → `1`

---

### КОРЕН
**Синтаксис:** `=КОРЕН(число)`

Изчислява квадратния корен.

```
=КОРЕН(A1)
```

---

### СЛУЧАЙНО
**Синтаксис:** `=СЛУЧАЙНО()`

Връща случайно десетично число между 0 и 1. Актуализира се при всяко преизчисляване.

```
=СЛУЧАЙНО()
```

> За случайно число между 1 и 100: `=ЦЯЛО(СЛУЧАЙНО()*100)+1`

---

## Абсолютни референции

В програмата режимът на референция може да се избере от падащо меню:

| Режим | Пример | Значение |
|-------|--------|---------|
| Относителна | `A1` | Измества се при копиране |
| Фиксирана колона | `$A1` | Колоната остава, редът се измества |
| Фиксиран ред | `A$1` | Редът остава, колоната се измества |
| Абсолютна | `$A$1` | Остава непроменена при копиране |
