# مرجع الدوال – مساعد صيغ LibreOffice Calc

جميع الدوال المتاحة في البرنامج، مع بناء الجملة والمعاملات والأمثلة.

---

## علامة التبويب 1 – الدوال الأساسية

### المعاملات الحسابية

| المعامل | المعنى | مثال | النتيجة |
|---------|--------|------|---------|
| `+` | جمع | `=A1+B1` | مجموع خليتين |
| `-` | طرح | `=A1-B1` | الفرق |
| `*` | ضرب | `=A1*B1` | الحاصل |
| `/` | قسمة | `=A1/B1` | الخارج |
| `^` | أس | `=A1^2` | A1 مربعاً |

---

### SUM
**بناء الجملة:** `=SUM(نطاق)`

يجمع جميع الأرقام في نطاق خلايا.

| المعامل | الوصف |
|---------|-------|
| `نطاق` | مثل `A1:A10` |

```
=SUM(A1:A10)
```

---

### AVERAGE
**بناء الجملة:** `=AVERAGE(نطاق)`

يحسب متوسط جميع الأرقام في النطاق.

```
=AVERAGE(A1:A10)
```

---

### MIN
**بناء الجملة:** `=MIN(نطاق)`

يُرجع أصغر قيمة في النطاق.

```
=MIN(A1:A10)
```

---

### MAX
**بناء الجملة:** `=MAX(نطاق)`

يُرجع أكبر قيمة في النطاق.

```
=MAX(A1:A10)
```

---

### COUNT
**بناء الجملة:** `=COUNT(نطاق)`

يعد جميع الخلايا التي تحتوي على **قيم رقمية** في النطاق.

```
=COUNT(A1:A10)
```

---

### COUNTA
**بناء الجملة:** `=COUNTA(نطاق)`

يعد جميع الخلايا **غير الفارغة** (أرقام ونصوص).

```
=COUNTA(A1:A10)
```

---

### MEDIAN
**بناء الجملة:** `=MEDIAN(نطاق)`

يُرجع القيمة الوسطى لقائمة القيم المرتبة.

```
=MEDIAN(A1:A10)
```

---

### SUMPRODUCT
**بناء الجملة:** `=SUMPRODUCT(نطاق1; نطاق2)`

يضرب عناصر نطاقين ببعضهما ويجمع النتائج.

| المعامل | الوصف |
|---------|-------|
| `نطاق1` | النطاق الأول |
| `نطاق2` | النطاق الثاني (نفس الحجم) |

```
=SUMPRODUCT(A1:A10; B1:B10)
```

## علامة التبويب 2 – الدوال المتقدمة

### IF
**بناء الجملة:** `=IF(شرط; إذا_صح; إذا_خطأ)`

يُرجع إحدى قيمتين بحسب ما إذا كان الشرط صحيحاً أم خاطئاً.

| المعامل | الوصف |
|---------|-------|
| `شرط` | مثل `A1>0` |
| `إذا_صح` | القيمة إذا كان صحيحاً |
| `إذا_خطأ` | القيمة إذا كان خاطئاً |

```
=IF(A1>0; "صحيح"; "خطأ")
```

---

### AND
**بناء الجملة:** `=AND(شرط1; شرط2)`

يُرجع TRUE إذا تحققت **جميع** الشروط.

```
=AND(A1>0; B1>0)
```

---

### OR
**بناء الجملة:** `=OR(شرط1; شرط2)`

يُرجع TRUE إذا تحقق **شرط واحد على الأقل**.

```
=OR(A1>0; B1>0)
```

---

### NOT
**بناء الجملة:** `=NOT(شرط)`

يعكس قيمة منطقية: TRUE → FALSE، FALSE → TRUE.

```
=NOT(A1>0)
```

---

### SUMIF
**بناء الجملة:** `=SUMIF(نطاق; معيار; نطاق_الجمع)`

يجمع القيم التي تطابق معياراً.

| المعامل | الوصف |
|---------|-------|
| `نطاق` | النطاق الذي يُفحص |
| `معيار` | مثل `">10"` أو `"نعم"` |
| `نطاق_الجمع` | النطاق الذي يُجمع |

```
=SUMIF(A1:A10; ">10"; B1:B10)
```

---

### COUNTIF
**بناء الجملة:** `=COUNTIF(نطاق; معيار)`

يعد الخلايا التي تطابق معياراً.

```
=COUNTIF(A1:A10; "نعم")
```

---

### AVERAGEIF
**بناء الجملة:** `=AVERAGEIF(نطاق; معيار; نطاق_المتوسط)`

يحسب متوسط القيم التي تطابق معياراً.

```
=AVERAGEIF(A1:A10; ">0"; B1:B10)
```

---

### SUMIFS
**بناء الجملة:** `=SUMIFS(نطاق_الجمع; نطاق_المعيار; معيار)`

يجمع القيم التي تطابق **معايير متعددة**.

| المعامل | الوصف |
|---------|-------|
| `نطاق_الجمع` | النطاق الذي يُجمع |
| `نطاق_المعيار` | النطاق الذي يُفحص |
| `معيار` | الشرط، مثل `">10"` |

```
=SUMIFS(A1:A10; B1:B10; ">10")
```

---

### STDEV
**بناء الجملة:** `=STDEV(نطاق)`

يحسب الانحراف المعياري (تشتت القيم).

```
=STDEV(A1:A10)
```

---

### VAR
**بناء الجملة:** `=VAR(نطاق)`

يحسب التباين (التشتت التربيعي).

```
=VAR(A1:A10)
```

---

### COUNTBLANK
**بناء الجملة:** `=COUNTBLANK(نطاق)`

يعد جميع الخلايا **الفارغة** في النطاق.

```
=COUNTBLANK(A1:A10)
```

---

### LARGE
**بناء الجملة:** `=LARGE(نطاق; k)`

يُرجع القيمة الأكبر k في النطاق.

| المعامل | الوصف |
|---------|-------|
| `نطاق` | نطاق الأرقام |
| `k` | الترتيب (1 = الأكبر، 2 = الثاني الأكبر، …) |

```
=LARGE(A1:A10; 2)
```

## علامة التبويب 3 – التاريخ والنص

### TODAY
**بناء الجملة:** `=TODAY()`

يُرجع التاريخ الحالي. يُحدَّث في كل مرة يُفتح فيها الملف.

```
=TODAY()
```

---

### NOW
**بناء الجملة:** `=NOW()`

يُرجع التاريخ الحالي **مع الوقت**.

```
=NOW()
```

---

### YEAR
**بناء الجملة:** `=YEAR(تاريخ)`

يستخرج السنة من تاريخ.

```
=YEAR(A1)
```

---

### MONTH
**بناء الجملة:** `=MONTH(تاريخ)`

يستخرج الشهر (1–12) من تاريخ.

```
=MONTH(A1)
```

---

### DAY
**بناء الجملة:** `=DAY(تاريخ)`

يستخرج اليوم (1–31) من تاريخ.

```
=DAY(A1)
```

---

### DATE
**بناء الجملة:** `=DATE(سنة; شهر; يوم)`

ينشئ تاريخاً من قيم منفردة.

```
=DATE(2025; 1; 1)
```

---

### DATEDIF
**بناء الجملة:** `=DATEDIF(تاريخ_البداية; تاريخ_النهاية; وحدة)`

يحسب الفرق بين تاريخين.

| الوحدة | المعنى |
|--------|--------|
| `"D"` | أيام |
| `"M"` | أشهر |
| `"Y"` | سنوات |

```
=DATEDIF(A1; B1; "D")
```

> **ملاحظة:** DATEDIF دالة غير موثقة – تعمل في LibreOffice وExcel، لكنها لا تظهر في الإكمال التلقائي.

---

### WEEKDAY
**بناء الجملة:** `=WEEKDAY(تاريخ; نوع)`

يُرجع يوم الأسبوع كرقم.

| النوع | المعنى |
|-------|--------|
| `2` | 1=إثنين، 2=ثلاثاء، … 7=أحد (موصى به) |
| `1` | 1=أحد، 2=إثنين، … 7=سبت |

```
=WEEKDAY(A1; 2)
```

---

### CONCATENATE
**بناء الجملة:** `=CONCATENATE(نص1; نص2; …)`

يدمج عدة نصوص في نص واحد.

```
=CONCATENATE(A1; " "; B1)
```

---

### LEN
**بناء الجملة:** `=LEN(نص)`

يُرجع عدد الأحرف في نص.

```
=LEN(A1)
```

---

### LEFT
**بناء الجملة:** `=LEFT(نص; عدد)`

يُرجع أول n أحرف من نص.

```
=LEFT(A1; 5)
```

---

### RIGHT
**بناء الجملة:** `=RIGHT(نص; عدد)`

يُرجع آخر n أحرف من نص.

```
=RIGHT(A1; 5)
```

---

### MID
**بناء الجملة:** `=MID(نص; موضع_البداية; عدد)`

يُرجع مقطعاً من نص.

| المعامل | الوصف |
|---------|-------|
| `نص` | النص المصدر |
| `موضع_البداية` | من أي حرف يبدأ (1 = الأول) |
| `عدد` | عدد الأحرف |

```
=MID(A1; 1; 5)
```

---

### UPPER
**بناء الجملة:** `=UPPER(نص)`

يحوّل جميع الأحرف إلى أحرف كبيرة.

```
=UPPER(A1)
```

---

### LOWER
**بناء الجملة:** `=LOWER(نص)`

يحوّل جميع الأحرف إلى أحرف صغيرة.

```
=LOWER(A1)
```

---

### TRIM
**بناء الجملة:** `=TRIM(نص)`

يزيل المسافات الزائدة (في البداية والنهاية والمكررة).

```
=TRIM(A1)
```

## علامة التبويب 4 – البحث والتقريب

### VLOOKUP
**بناء الجملة:** `=VLOOKUP(قيمة_البحث; جدول; رقم_العمود; تطابق)`

يبحث عن قيمة في **العمود الأول** من جدول ويُرجع قيمة من عمود آخر.

| المعامل | الوصف |
|---------|-------|
| `قيمة_البحث` | القيمة المطلوبة، مثل `A1` |
| `جدول` | نطاق البحث، مثل `B1:D10` |
| `رقم_العمود` | رقم عمود الإرجاع (1 = العمود الأول) |
| `تطابق` | `0` = تام، `1` = تقريبي |

```
=VLOOKUP(A1; B1:D10; 2; 0)
```

---

### HLOOKUP
**بناء الجملة:** `=HLOOKUP(قيمة_البحث; جدول; رقم_الصف; تطابق)`

مثل VLOOKUP، لكنه يبحث في **الصف الأول** (أفقياً).

```
=HLOOKUP(A1; B1:D10; 2; 0)
```

---

### INDEX
**بناء الجملة:** `=INDEX(نطاق; صف; عمود)`

يُرجع القيمة في موضع محدد داخل النطاق.

| المعامل | الوصف |
|---------|-------|
| `نطاق` | نطاق البحث |
| `صف` | رقم الصف |
| `عمود` | رقم العمود (افتراضي: 1) |

```
=INDEX(B1:B10; 3; 1)
```

---

### MATCH
**بناء الجملة:** `=MATCH(قيمة_البحث; نطاق_البحث; نوع_التطابق)`

يُرجع **موضع** قيمة داخل نطاق.

| نوع التطابق | المعنى |
|-------------|--------|
| `0` | تطابق تام |
| `1` | الأصغر الأكبر من أو يساوي |
| `-1` | الأكبر الأصغر من أو يساوي |

```
=MATCH(A1; A1:A10; 0)
```

---

### INDEX + MATCH
**بناء الجملة:** `=INDEX(نطاق_النتيجة; MATCH(قيمة_البحث; نطاق_البحث; 0))`

بديل أكثر مرونة لـ VLOOKUP – يمكنه البحث في **أي اتجاه**.

| المعامل | الوصف |
|---------|-------|
| `نطاق_النتيجة` | العمود الذي يحتوي على قيم الإرجاع |
| `قيمة_البحث` | القيمة المطلوبة |
| `نطاق_البحث` | العمود الذي يُبحث فيه |

```
=INDEX(B1:B10; MATCH(A1; A1:A10; 0))
```

> **ميزة على VLOOKUP:** لا يلزم أن يكون عمود البحث هو الأول. مستقر أيضاً عند إضافة/حذف الأعمدة.

---

### ROUND
**بناء الجملة:** `=ROUND(رقم; منازل_عشرية)`

يقرّب إلى عدد محدد من المنازل العشرية.

| المنازل العشرية | مثال |
|-----------------|------|
| `2` | 3.14159 → 3.14 |
| `0` | 3.7 → 4 |
| `-1` | 34 → 30 |

```
=ROUND(A1; 2)
```

---

### ROUNDUP
**بناء الجملة:** `=ROUNDUP(رقم; منازل_عشرية)`

يقرّب دائماً **للأعلى** (بعيداً عن الصفر).

```
=ROUNDUP(A1; 2)
```

---

### ROUNDDOWN
**بناء الجملة:** `=ROUNDDOWN(رقم; منازل_عشرية)`

يقرّب دائماً **للأسفل** (نحو الصفر).

```
=ROUNDDOWN(A1; 2)
```

---

### INT
**بناء الجملة:** `=INT(رقم)`

يقرّب إلى أقرب عدد صحيح **للأسفل** (حتى في الأرقام السالبة).

```
=INT(A1)
```

---

### TRUNC
**بناء الجملة:** `=TRUNC(رقم; منازل_عشرية)`

يقتطع المنازل العشرية **دون تقريب**.

```
=TRUNC(A1; 2)
```

---

### ABS
**بناء الجملة:** `=ABS(رقم)`

يُرجع **القيمة المطلقة** (دائماً موجبة).

```
=ABS(A1)
```

---

### MOD
**بناء الجملة:** `=MOD(رقم; مقسوم_عليه)`

يُرجع **باقي** القسمة.

```
=MOD(A1; 3)
```
> مثال: `=MOD(10; 3)` → `1`

---

### SQRT
**بناء الجملة:** `=SQRT(رقم)`

يحسب الجذر التربيعي.

```
=SQRT(A1)
```

---

### RAND
**بناء الجملة:** `=RAND()`

يُرجع رقماً عشرياً عشوائياً بين 0 و1. يُحدَّث عند كل إعادة حساب.

```
=RAND()
```

> للحصول على رقم عشوائي بين 1 و100: `=INT(RAND()*100)+1`

## المراجع المطلقة

في البرنامج يمكن اختيار وضع المرجع من القائمة المنسدلة:

| الوضع | مثال | المعنى |
|-------|------|--------|
| نسبي | `A1` | يتحرك عند النسخ |
| عمود ثابت | `$A1` | العمود ثابت، الصف يتحرك |
| صف ثابت | `A$1` | الصف ثابت، العمود يتحرك |
| مطلق | `$A$1` | ثابت دائماً عند النسخ |
