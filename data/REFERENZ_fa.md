# مرجع توابع – دستیار فرمول LibreOffice Calc

تمام توابع موجود در برنامه، با نحو، پارامترها و مثال‌ها.


## برگه ۱ – توابع پایه

### عملگرهای محاسباتی

| عملگر | معنا | مثال | نتیجه |
| - | - | - | - |
| `+` | جمع | `=A1+B1` | مجموع دو سلول |
| `-` | تفریق | `=A1-B1` | تفاضل |
| `*` | ضرب | `=A1*B1` | حاصل‌ضرب |
| `/` | تقسیم | `=A1/B1` | خارج قسمت |
| `^` | توان | `=A1^2` | A1 به توان ۲ |


### SUM (جمع)

**نحو:** `=SUM(محدوده)`

تمام اعداد در یک محدوده سلول را جمع می‌زند.

| پارامتر | توضیح |
| - | - |
| `محدوده` | مثلاً `A1:A10` |

```
=SUM(A1:A10)
```


### AVERAGE (میانگین)

**نحو:** `=AVERAGE(محدوده)`

میانگین تمام اعداد در محدوده را محاسبه می‌کند.

```
=AVERAGE(A1:A10)
```


### MIN (کمینه)

**نحو:** `=MIN(محدوده)`

کوچکترین مقدار در محدوده را برمی‌گرداند.

```
=MIN(A1:A10)
```


### MAX (بیشینه)

**نحو:** `=MAX(محدوده)`

بزرگترین مقدار در محدوده را برمی‌گرداند.

```
=MAX(A1:A10)
```


### COUNT (شمارش)

**نحو:** `=COUNT(محدوده)`

تمام سلول‌های دارای **مقدار عددی** در محدوده را می‌شمارد.

```
=COUNT(A1:A10)
```


### COUNTA (شمارش غیر خالی)

**نحو:** `=COUNTA(محدوده)`

تمام سلول‌های **غیر خالی** را می‌شمارد (اعداد و متن).

```
=COUNTA(A1:A10)
```


### MEDIAN (میانه)

**نحو:** `=MEDIAN(محدوده)`

مقدار میانی لیست مرتب‌شده را برمی‌گرداند.

```
=MEDIAN(A1:A10)
```


### SUMPRODUCT (حاصل‌ضرب مجموع)

**نحو:** `=SUMPRODUCT(محدوده۱; محدوده۲)`

عناصر دو محدوده را در هم ضرب کرده و نتایج را جمع می‌زند.

| پارامتر | توضیح |
| - | - |
| `محدوده۱` | محدوده اول |
| `محدوده۲` | محدوده دوم (همان اندازه) |

```
=SUMPRODUCT(A1:A10; B1:B10)
```


## برگه ۲ – توابع پیشرفته

### IF (اگر)

**نحو:** `=IF(شرط; آنگاه; وگرنه)`

بسته به اینکه شرط درست یا نادرست باشد، یکی از دو مقدار را برمی‌گرداند.

| پارامتر | توضیح |
| - | - |
| `شرط` | مثلاً `A1>0` |
| `آنگاه` | مقدار در صورت درستی |
| `وگرنه` | مقدار در صورت نادرستی |

```
=IF(A1>0; "OK"; "خطا")
```


### AND (و)

**نحو:** `=AND(شرط۱; شرط۲)`

TRUE برمی‌گرداند اگر **همه** شرط‌ها برقرار باشند.

```
=AND(A1>0; B1>0)
```


### OR (یا)

**نحو:** `=OR(شرط۱; شرط۲)`

TRUE برمی‌گرداند اگر **حداقل یک** شرط برقرار باشد.

```
=OR(A1>0; B1>0)
```


### NOT (نه)

**نحو:** `=NOT(شرط)`

یک مقدار منطقی را معکوس می‌کند: TRUE → FALSE، FALSE → TRUE.

```
=NOT(A1>0)
```


### SUMIF (جمع شرطی)

**نحو:** `=SUMIF(محدوده; معیار; محدوده_جمع)`

مقادیری را که با یک معیار مطابقت دارند جمع می‌زند.

| پارامتر | توضیح |
| - | - |
| `محدوده` | محدوده‌ای که بررسی می‌شود |
| `معیار` | مثلاً `">10"` یا `"بله"` |
| `محدوده_جمع` | محدوده‌ای که جمع می‌شود |

```
=SUMIF(A1:A10; ">10"; B1:B10)
```


### COUNTIF (شمارش شرطی)

**نحو:** `=COUNTIF(محدوده; معیار)`

سلول‌هایی را که با یک معیار مطابقت دارند می‌شمارد.

```
=COUNTIF(A1:A10; "بله")
```


### AVERAGEIF (میانگین شرطی)

**نحو:** `=AVERAGEIF(محدوده; معیار; محدوده_میانگین)`

میانگین مقادیری را که با یک معیار مطابقت دارند محاسبه می‌کند.

```
=AVERAGEIF(A1:A10; ">0"; B1:B10)
```


### SUMIFS (جمع چندشرطی)

**نحو:** `=SUMIFS(محدوده_جمع; محدوده_معیار; معیار)`

مقادیری را که با **چند** معیار مطابقت دارند جمع می‌زند.

| پارامتر | توضیح |
| - | - |
| `محدوده_جمع` | محدوده‌ای که جمع می‌شود |
| `محدوده_معیار` | محدوده‌ای که بررسی می‌شود |
| `معیار` | شرط مثلاً `">10"` |

```
=SUMIFS(A1:A10; B1:B10; ">10")
```


### STDEV (انحراف معیار)

**نحو:** `=STDEV(محدوده)`

انحراف معیار (پراکندگی مقادیر) را محاسبه می‌کند.

```
=STDEV(A1:A10)
```


### VAR (واریانس)

**نحو:** `=VAR(محدوده)`

واریانس (پراکندگی مربعی) را محاسبه می‌کند.

```
=VAR(A1:A10)
```


### COUNTBLANK (شمارش خالی)

**نحو:** `=COUNTBLANK(محدوده)`

تمام سلول‌های **خالی** در محدوده را می‌شمارد.

```
=COUNTBLANK(A1:A10)
```


### LARGE (بزرگترین k-ام)

**نحو:** `=LARGE(محدوده; k)`

k-امین مقدار بزرگ در محدوده را برمی‌گرداند.

| پارامتر | توضیح |
| - | - |
| `محدوده` | محدوده اعداد |
| `k` | رتبه (1 = بزرگترین، 2 = دومین بزرگ، …) |

```
=LARGE(A1:A10; 2)
```


## برگه ۳ – تاریخ و متن

### TODAY (امروز)

**نحو:** `=TODAY()`

تاریخ جاری را برمی‌گرداند. با هر بار باز شدن فایل به‌روزرسانی می‌شود.

```
=TODAY()
```


### NOW (اکنون)

**نحو:** `=NOW()`

تاریخ جاری **به همراه زمان** را برمی‌گرداند.

```
=NOW()
```


### YEAR (سال)

**نحو:** `=YEAR(تاریخ)`

سال را از یک تاریخ استخراج می‌کند.

```
=YEAR(A1)
```


### MONTH (ماه)

**نحو:** `=MONTH(تاریخ)`

ماه (۱–۱۲) را از یک تاریخ استخراج می‌کند.

```
=MONTH(A1)
```


### DAY (روز)

**نحو:** `=DAY(تاریخ)`

روز (۱–۳۱) را از یک تاریخ استخراج می‌کند.

```
=DAY(A1)
```


### DATE (تاریخ)

**نحو:** `=DATE(سال; ماه; روز)`

یک تاریخ از مقادیر جداگانه می‌سازد.

```
=DATE(2025; 1; 1)
```


### DATEDIF (اختلاف تاریخ)

**نحو:** `=DATEDIF(تاریخ_شروع; تاریخ_پایان; واحد)`

اختلاف بین دو تاریخ را محاسبه می‌کند.

| واحد | معنا |
| - | - |
| `"D"` | روز |
| `"M"` | ماه |
| `"Y"` | سال |

```
=DATEDIF(A1; B1; "D")
```

> **توجه:** DATEDIF یک تابع مستندنشده است – در LibreOffice و Excel کار می‌کند اما در تکمیل خودکار نمایش داده نمی‌شود.


### WEEKDAY (روز هفته)

**نحو:** `=WEEKDAY(تاریخ; نوع)`

روز هفته را به صورت عدد برمی‌گرداند.

| نوع | معنا |
| - | - |
| `2` | 1=دوشنبه، 2=سه‌شنبه، … 7=یکشنبه (پیشنهادی) |
| `1` | 1=یکشنبه، 2=دوشنبه، … 7=شنبه |

```
=WEEKDAY(A1; 2)
```


### CONCATENATE (پیوند متن)

**نحو:** `=CONCATENATE(متن۱; متن۲; …)`

چند متن را به هم متصل می‌کند.

```
=CONCATENATE(A1; " "; B1)
```


### LEN (طول)

**نحو:** `=LEN(متن)`

تعداد کاراکترهای یک متن را برمی‌گرداند.

```
=LEN(A1)
```


### LEFT (چپ)

**نحو:** `=LEFT(متن; تعداد)`

n کاراکتر اول یک متن را برمی‌گرداند.

```
=LEFT(A1; 5)
```


### RIGHT (راست)

**نحو:** `=RIGHT(متن; تعداد)`

n کاراکتر آخر یک متن را برمی‌گرداند.

```
=RIGHT(A1; 5)
```


### MID (میانی)

**نحو:** `=MID(متن; موقعیت_شروع; تعداد)`

یک بخش از متن را برمی‌گرداند.

| پارامتر | توضیح |
| - | - |
| `متن` | متن منبع |
| `موقعیت_شروع` | از کدام کاراکتر (1 = اول) |
| `تعداد` | چند کاراکتر |

```
=MID(A1; 1; 5)
```


### UPPER (حروف بزرگ)

**نحو:** `=UPPER(متن)`

تمام حروف را به **حروف بزرگ** تبدیل می‌کند.

```
=UPPER(A1)
```


### LOWER (حروف کوچک)

**نحو:** `=LOWER(متن)`

تمام حروف را به **حروف کوچک** تبدیل می‌کند.

```
=LOWER(A1)
```


### TRIM (حذف فاصله)

**نحو:** `=TRIM(متن)`

فاصله‌های اضافی را حذف می‌کند (ابتدا، انتها، دوتایی).

```
=TRIM(A1)
```


## برگه ۴ – جستجو و گرد کردن

### VLOOKUP (جستجوی عمودی)

**نحو:** `=VLOOKUP(مقدار_جستجو; ماتریس; شماره_ستون; تطابق)`

یک مقدار را در **اولین ستون** یک جدول جستجو می‌کند و مقدار ستون دیگری را برمی‌گرداند.

| پارامتر | توضیح |
| - | - |
| `مقدار_جستجو` | مقدار مورد جستجو، مثلاً `A1` |
| `ماتریس` | محدوده جستجو، مثلاً `B1:D10` |
| `شماره_ستون` | شماره ستون برای بازگشت (1 = اولین ستون) |
| `تطابق` | `0` = دقیق، `1` = تقریبی |

```
=VLOOKUP(A1; B1:D10; 2; 0)
```


### HLOOKUP (جستجوی افقی)

**نحو:** `=HLOOKUP(مقدار_جستجو; ماتریس; شماره_ردیف; تطابق)`

مانند VLOOKUP، اما در **اولین ردیف** جستجو می‌کند (افقی).

```
=HLOOKUP(A1; B1:D10; 2; 0)
```


### INDEX

**نحو:** `=INDEX(محدوده; ردیف; ستون)`

مقدار در یک موقعیت مشخص در محدوده را برمی‌گرداند.

| پارامتر | توضیح |
| - | - |
| `محدوده` | محدوده جستجو |
| `ردیف` | شماره ردیف |
| `ستون` | شماره ستون (پیش‌فرض: 1) |

```
=INDEX(B1:B10; 3; 1)
```


### MATCH (تطابق)

**نحو:** `=MATCH(مقدار_جستجو; محدوده_جستجو; نوع_تطابق)`

**موقعیت** یک مقدار در محدوده را برمی‌گرداند.

| نوع تطابق | معنا |
| - | - |
| `0` | تطابق دقیق |
| `1` | کوچکترینی که بزرگتر یا مساوی است |
| `-1` | بزرگترینی که کوچکتر یا مساوی است |

```
=MATCH(A1; A1:A10; 0)
```


### INDEX + MATCH (ترکیب)

**نحو:** `=INDEX(محدوده_نتیجه; MATCH(مقدار_جستجو; محدوده_جستجو; 0))`

جایگزین انعطاف‌پذیرتر VLOOKUP – می‌تواند در **هر جهتی** جستجو کند.

| پارامتر | توضیح |
| - | - |
| `محدوده_نتیجه` | ستون با مقادیر بازگشتی |
| `مقدار_جستجو` | مقدار مورد جستجو |
| `محدوده_جستجو` | ستونی که در آن جستجو می‌شود |

```
=INDEX(B1:B10; MATCH(A1; A1:A10; 0))
```

> **مزیت نسبت به VLOOKUP:** ستون جستجو نباید اولین ستون باشد. در صورت درج/حذف ستون نیز پایدار است.


### ROUND (گرد کردن)

**نحو:** `=ROUND(عدد; تعداد_اعشار)`

به تعداد اعشار مشخص گرد می‌کند.

| تعداد اعشار | مثال |
| - | - |
| `2` | 3.14159 → 3.14 |
| `0` | 3.7 → 4 |
| `-1` | 34 → 30 |

```
=ROUND(A1; 2)
```


### ROUNDUP (گرد به بالا)

**نحو:** `=ROUNDUP(عدد; تعداد_اعشار)`

همیشه **به بالا** گرد می‌کند (دور از صفر).

```
=ROUNDUP(A1; 2)
```


### ROUNDDOWN (گرد به پایین)

**نحو:** `=ROUNDDOWN(عدد; تعداد_اعشار)`

همیشه **به پایین** گرد می‌کند (به سمت صفر).

```
=ROUNDDOWN(A1; 2)
```


### INT (عدد صحیح)

**نحو:** `=INT(عدد)`

به نزدیکترین عدد صحیح **رو به پایین** گرد می‌کند (حتی برای اعداد منفی).

```
=INT(A1)
```


### TRUNC (قطع اعشار)

**نحو:** `=TRUNC(عدد; تعداد_اعشار)`

اعشار را **بدون گرد کردن** قطع می‌کند.

```
=TRUNC(A1; 2)
```


### ABS (قدر مطلق)

**نحو:** `=ABS(عدد)`

**قدر مطلق** (همیشه مثبت) را برمی‌گرداند.

```
=ABS(A1)
```


### MOD (باقیمانده)

**نحو:** `=MOD(عدد; مقسوم_علیه)`

**باقیمانده** یک تقسیم را برمی‌گرداند.

```
=MOD(A1; 3)
```

> مثال: `=MOD(10; 3)` → `1`


### SQRT (جذر)

**نحو:** `=SQRT(عدد)`

جذر مربعی را محاسبه می‌کند.

```
=SQRT(A1)
```


### RAND (تصادفی)

**نحو:** `=RAND()`

یک عدد اعشاری تصادفی بین 0 و 1 برمی‌گرداند. با هر محاسبه مجدد به‌روزرسانی می‌شود.

```
=RAND()
```

> برای عدد تصادفی بین 1 و 100: `=INT(RAND()*100)+1`


## مرجع مطلق

در برنامه، حالت مرجع از طریق منوی کشویی قابل انتخاب است:

| حالت | مثال | معنا |
| - | - | - |
| نسبی | `A1` | هنگام کپی جابجا می‌شود |
| ستون ثابت | `$A1` | ستون ثابت، ردیف جابجا می‌شود |
| ردیف ثابت | `A$1` | ردیف ثابت، ستون جابجا می‌شود |
| مطلق | `$A$1` | هنگام کپی همیشه ثابت می‌ماند |
