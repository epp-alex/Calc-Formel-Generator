# Αναφορά συναρτήσεων – LibreOffice Calc Formula Helper

Όλες οι συναρτήσεις που είναι διαθέσιμες στο πρόγραμμα, με σύνταξη, παραμέτρους και παραδείγματα.

## Καρτέλα 1 – Βασικές συναρτήσεις

### Αριθμητικοί τελεστές

| **Τελεστής** | **Σημασία** | **Παράδειγμα** | **Αποτέλεσμα** |
| :-: | :-: | :-: | :-: |
| `+` | Πρόσθεση | `=A1+B1` | Άθροισμα δύο κελιών |
| `-` | Αφαίρεση | `=A1-B1` | Διαφορά |
| `\\\*` | Πολλαπλασιασμός | `=A1\\\*B1` | Γινόμενο |
| `/` | Διαίρεση | `=A1/B1` | Πηλίκο |
| `^` | Ύψωση σε δύναμη | `=A1^2` | A1 στο τετράγωνο |


### ΑΘΡΟΙΣΜΑ

**Σύνταξη:** `=ΑΘΡΟΙΣΜΑ(περιοχή)`

Αθροίζει όλους τους αριθμούς σε μια περιοχή κελιών.

| **Παράμετρος** | **Περιγραφή** |
| :-: | :-: |
| `περιοχή` | π.χ. `A1:A10` |


```
\`=ΑΘΡΟΙΣΜΑ(A1:A10)\`
```

### ΜΕΣΟΣ.ΟΡΟΣ

**Σύνταξη:** `=ΜΕΣΟΣ.ΟΡΟΣ(περιοχή)`

Υπολογίζει τον μέσο όρο όλων των αριθμών στην περιοχή.

```
\`=ΜΕΣΟΣ.ΟΡΟΣ(A1:A10)\`
```

### MIN

**Σύνταξη:** `=MIN(περιοχή)`

Επιστρέφει τη μικρότερη τιμή στην περιοχή.

```
\`=MIN(A1:A10)\`
```

### MAX

**Σύνταξη:** `=MAX(περιοχή)`

Επιστρέφει τη μεγαλύτερη τιμή στην περιοχή.

```
\`=MAX(A1:A10)\`
```

### ΠΛΗΘΟΣ

**Σύνταξη:** `=ΠΛΗΘΟΣ(περιοχή)`

Μετράει όλα τα κελιά με **αριθμητικές τιμές** στην περιοχή.

```
\`=ΠΛΗΘΟΣ(A1:A10)\`
```

### ΠΛΗΘΟΣ2

**Σύνταξη:** `=ΠΛΗΘΟΣ2(περιοχή)`

Μετράει όλα τα **μη κενά** κελιά (αριθμοί και κείμενο).

```
\`=ΠΛΗΘΟΣ2(A1:A10)\`
```

### ΔΙΑΜΕΣΟΣ

**Σύνταξη:** `=ΔΙΑΜΕΣΟΣ(περιοχή)`

Επιστρέφει τη διάμεσο της ταξινομημένης λίστας τιμών (μεσαία τιμή).

```
\`=ΔΙΑΜΕΣΟΣ(A1:A10)\`
```

### ΑΘΡΟΙΣΜΑΓΙΝΟΜΕΝΩΝ

**Σύνταξη:** `=ΑΘΡΟΙΣΜΑΓΙΝΟΜΕΝΩΝ(περιοχή1; περιοχή2)`

Πολλαπλασιάζει τα στοιχεία δύο περιοχών μεταξύ τους και αθροίζει τα αποτελέσματα.

| **Παράμετρος** | **Περιγραφή** |
| :-: | :-: |
| `περιοχή1` | Πρώτη περιοχή |
| `περιοχή2` | Δεύτερη περιοχή (ίδιο μέγεθος) |


```
\`=ΑΘΡΟΙΣΜΑΓΙΝΟΜΕΝΩΝ(A1:A10; B1:B10)\`
```

## Καρτέλα 2 – Προχωρημένες συναρτήσεις

### ΑΝ

**Σύνταξη:** `=ΑΝ(συνθήκη; τότε; αλλιώς)`

Επιστρέφει μία από δύο τιμές ανάλογα με το αν η συνθήκη είναι αληθής ή ψευδής.

| **Παράμετρος** | **Περιγραφή** |
| :-: | :-: |
| `συνθήκη` | π.χ. `A1\\\>0` |
| `τότε` | Τιμή αν αληθής |
| `αλλιώς` | Τιμή αν ψευδής |


```
\`=ΑΝ(A1\\\>0; "ΟΚ"; "Σφάλμα")\`
```

### ΚΑΙ

**Σύνταξη:** `=ΚΑΙ(συνθήκη1; συνθήκη2)`

Επιστρέφει ΑΛΗΘΗΣ αν **όλες** οι συνθήκες πληρούνται.

```
\`=ΚΑΙ(A1\\\>0; B1\\\>0)\`
```

### Ή

**Σύνταξη:** `=Ή(συνθήκη1; συνθήκη2)`

Επιστρέφει ΑΛΗΘΗΣ αν **τουλάχιστον μία** συνθήκη πληρούται.

```
\`=Ή(A1\\\>0; B1\\\>0)\`
```

### ΟΧΙ

**Σύνταξη:** `=ΟΧΙ(συνθήκη)`

Αντιστρέφει μια λογική τιμή: ΑΛΗΘΗΣ → ΨΕΥΔΗΣ, ΨΕΥΔΗΣ → ΑΛΗΘΗΣ.

```
\`=ΟΧΙ(A1\\\>0)\`
```

### ΑΘΡΟΙΣΜΑ.ΑΝ

**Σύνταξη:** `=ΑΘΡΟΙΣΜΑ.ΑΝ(περιοχή; κριτήριο; περιοχή\\\_αθροίσματος)`

Αθροίζει τιμές που πληρούν ένα κριτήριο.

| **Παράμετρος** | **Περιγραφή** |
| :-: | :-: |
| `περιοχή` | Περιοχή που ελέγχεται |
| `κριτήριο` | π.χ. `"\\\>10"` ή `"Ναι"` |
| `περιοχή\\\_αθροίσματος` | Περιοχή που αθροίζεται |


```
\`=ΑΘΡΟΙΣΜΑ.ΑΝ(A1:A10; "\\\>10"; B1:B10)\`
```

### ΠΛΗΘΟΣ.ΑΝ

**Σύνταξη:** `=ΠΛΗΘΟΣ.ΑΝ(περιοχή; κριτήριο)`

Μετράει κελιά που πληρούν ένα κριτήριο.

```
\`=ΠΛΗΘΟΣ.ΑΝ(A1:A10; "Ναι")\`
```

### ΜΕΣΟΣ.ΟΡΟΣ.ΑΝ

**Σύνταξη:** `=ΜΕΣΟΣ.ΟΡΟΣ.ΑΝ(περιοχή; κριτήριο; περιοχή\\\_μέσου\\\_όρου)`

Υπολογίζει τον μέσο όρο τιμών που πληρούν ένα κριτήριο.

```
\`=ΜΕΣΟΣ.ΟΡΟΣ.ΑΝ(A1:A10; "\\\>0"; B1:B10)\`
```

### ΑΘΡΟΙΣΜΑ.ΑΝΣ

**Σύνταξη:** `=ΑΘΡΟΙΣΜΑ.ΑΝΣ(περιοχή\\\_αθροίσματος; περιοχή\\\_κριτηρίων; κριτήριο)`

Αθροίζει τιμές που πληρούν **πολλαπλά** κριτήρια.

| **Παράμετρος** | **Περιγραφή** |
| :-: | :-: |
| `περιοχή\\\_αθροίσματος` | Περιοχή που αθροίζεται |
| `περιοχή\\\_κριτηρίων` | Περιοχή που ελέγχεται |
| `κριτήριο` | Συνθήκη π.χ. `"\\\>10"` |


```
\`=ΑΘΡΟΙΣΜΑ.ΑΝΣ(A1:A10; B1:B10; "\\\>10")\`
```

### ΤΥΠΑΠΚΛ

**Σύνταξη:** `=ΤΥΠΑΠΚΛ(περιοχή)`

Υπολογίζει την τυπική απόκλιση (διασπορά τιμών).

```
\`=ΤΥΠΑΠΚΛ(A1:A10)\`
```

### ΔΙΑΚΥΜΑΝΣΗ

**Σύνταξη:** `=ΔΙΑΚΥΜΑΝΣΗ(περιοχή)`

Υπολογίζει τη διακύμανση (τετραγωνική διασπορά).

```
\`=ΔΙΑΚΥΜΑΝΣΗ(A1:A10)\`
```

### ΠΛΗΘΟΣ.ΚΕΝΩΝ

**Σύνταξη:** `=ΠΛΗΘΟΣ.ΚΕΝΩΝ(περιοχή)`

Μετράει όλα τα **κενά** κελιά στην περιοχή.

```
\`=ΠΛΗΘΟΣ.ΚΕΝΩΝ(A1:A10)\`
```

### ΜΕΓΑΛΟΣ

**Σύνταξη:** `=ΜΕΓΑΛΟΣ(περιοχή; k)`

Επιστρέφει την k-οστή μεγαλύτερη τιμή στην περιοχή.

| **Παράμετρος** | **Περιγραφή** |
| :-: | :-: |
| `περιοχή` | Αριθμητική περιοχή |
| `k` | Κατάταξη (1 = μεγαλύτερη, 2 = δεύτερη μεγαλύτερη, …) |


```
\`=ΜΕΓΑΛΟΣ(A1:A10; 2)\`
```

## Καρτέλα 3 – Ημερομηνία και κείμενο

### ΣΗΜΕΡΑ

**Σύνταξη:** `=ΣΗΜΕΡΑ()`

Επιστρέφει την τρέχουσα ημερομηνία. Ενημερώνεται κάθε φορά που ανοίγει το αρχείο.

```
\`=ΣΗΜΕΡΑ()\`
```

### ΤΩΡΑ

**Σύνταξη:** `=ΤΩΡΑ()`

Επιστρέφει την τρέχουσα ημερομηνία **με ώρα**.

```
\`=ΤΩΡΑ()\`
```

### ΕΤΟΣ

**Σύνταξη:** `=ΕΤΟΣ(ημερομηνία)`

Εξάγει το έτος από μια ημερομηνία.

```
\`=ΕΤΟΣ(A1)\`
```

### ΜΗΝΑΣ

**Σύνταξη:** `=ΜΗΝΑΣ(ημερομηνία)`

Εξάγει τον μήνα (1–12) από μια ημερομηνία.

```
\`=ΜΗΝΑΣ(A1)\`
```

### ΗΜΕΡΑ

**Σύνταξη:** `=ΗΜΕΡΑ(ημερομηνία)`

Εξάγει την ημέρα (1–31) από μια ημερομηνία.

```
\`=ΗΜΕΡΑ(A1)\`
```

### ΗΜΕΡΟΜΗΝΙΑ

**Σύνταξη:** `=ΗΜΕΡΟΜΗΝΙΑ(έτος; μήνας; ημέρα)`

Δημιουργεί μια ημερομηνία από επιμέρους τιμές.

```
\`=ΗΜΕΡΟΜΗΝΙΑ(2025; 1; 1)\`
```

### DATEDIF

**Σύνταξη:** `=DATEDIF(ημερομηνία\\\_έναρξης; ημερομηνία\\\_λήξης; μονάδα)`

Υπολογίζει τη διαφορά μεταξύ δύο ημερομηνιών.

| **Μονάδα** | **Σημασία** |
| :-: | :-: |
| `"D"` | Ημέρες |
| `"M"` | Μήνες |
| `"Y"` | Έτη |


```
\`=DATEDIF(A1; B1; "D")\`
```

> **Σημείωση:** Η DATEDIF είναι αδοκύμαντη συνάρτηση – λειτουργεί στο LibreOffice και το Excel, αλλά δεν εμφανίζεται στην αυτόματη συμπλήρωση.

### ΗΜΕΡΑ.ΕΒΔΟΜΑΔΑΣ

**Σύνταξη:** `=ΗΜΕΡΑ.ΕΒΔΟΜΑΔΑΣ(ημερομηνία; τύπος)`

Επιστρέφει την ημέρα της εβδομάδας ως αριθμό.

| **Τύπος** | **Σημασία** |
| :-: | :-: |
| `2` | 1=Δευ, 2=Τρι, … 7=Κυρ (προτεινόμενο) |
| `1` | 1=Κυρ, 2=Δευ, … 7=Σαβ |


```
\`=ΗΜΕΡΑ.ΕΒΔΟΜΑΔΑΣ(A1; 2)\`
```

### ΣΥΝΕΝΩΣΗ

**Σύνταξη:** `=ΣΥΝΕΝΩΣΗ(κείμενο1; κείμενο2; …)`

Συνενώνει πολλά κείμενα σε ένα.

```
\`=ΣΥΝΕΝΩΣΗ(A1; " "; B1)\`
```

### ΜΗΚΟΣ

**Σύνταξη:** `=ΜΗΚΟΣ(κείμενο)`

Επιστρέφει τον αριθμό χαρακτήρων σε ένα κείμενο.

```
\`=ΜΗΚΟΣ(A1)\`
```

### ΑΡΙΣΤΕΡΑ

**Σύνταξη:** `=ΑΡΙΣΤΕΡΑ(κείμενο; πλήθος)`

Επιστρέφει τους πρώτους n χαρακτήρες ενός κειμένου.

```
\`=ΑΡΙΣΤΕΡΑ(A1; 5)\`
```

### ΔΕΞΙΑ

**Σύνταξη:** `=ΔΕΞΙΑ(κείμενο; πλήθος)`

Επιστρέφει τους τελευταίους n χαρακτήρες ενός κειμένου.

```
\`=ΔΕΞΙΑ(A1; 5)\`
```

### ΜΕΣΟ

**Σύνταξη:** `=ΜΕΣΟ(κείμενο; αρχική\\\_θέση; πλήθος)`

Επιστρέφει ένα τμήμα κειμένου.

| **Παράμετρος** | **Περιγραφή** |
| :-: | :-: |
| `κείμενο` | Κείμενο πηγής |
| `αρχική\\\_θέση` | Από ποιον χαρακτήρα (1 = πρώτος) |
| `πλήθος` | Πόσοι χαρακτήρες |


```
\`=ΜΕΣΟ(A1; 1; 5)\`
```

### ΚΕΦΑΛΑΙΑ

**Σύνταξη:** `=ΚΕΦΑΛΑΙΑ(κείμενο)`

Μετατρέπει όλα τα γράμματα σε κεφαλαία.

```
\`=ΚΕΦΑΛΑΙΑ(A1)\`
```

### ΠΕΖΑ

**Σύνταξη:** `=ΠΕΖΑ(κείμενο)`

Μετατρέπει όλα τα γράμματα σε πεζά.

```
\`=ΠΕΖΑ(A1)\`
```

### ΕΚΚΑΘΑΡΙΣΗ

**Σύνταξη:** `=ΕΚΚΑΘΑΡΙΣΗ(κείμενο)`

Αφαιρεί τα περιττά κενά (αρχικά, τελικά και διπλά).

```
\`=ΕΚΚΑΘΑΡΙΣΗ(A1)\`
```

## Καρτέλα 4 – Αναζήτηση και στρογγυλοποίηση

### VLOOKUP

**Σύνταξη:** `=VLOOKUP(τιμή\\\_αναζήτησης; πίνακας; δείκτης\\\_στήλης; αντιστοίχιση)`

Αναζητά μια τιμή στην **πρώτη στήλη** ενός πίνακα και επιστρέφει την τιμή από άλλη στήλη.

| **Παράμετρος** | **Περιγραφή** |
| :-: | :-: |
| `τιμή\\\_αναζήτησης` | Αναζητούμενη τιμή, π.χ. `A1` |
| `πίνακας` | Περιοχή αναζήτησης, π.χ. `B1:D10` |
| `δείκτης\\\_στήλης` | Αριθμός στήλης επιστροφής (1 = πρώτη στήλη) |
| `αντιστοίχιση` | `0` = ακριβής, `1` = κατά προσέγγιση |


```
\`=VLOOKUP(A1; B1:D10; 2; 0)\`
```

### HLOOKUP

**Σύνταξη:** `=HLOOKUP(τιμή\\\_αναζήτησης; πίνακας; δείκτης\\\_γραμμής; αντιστοίχιση)`

Όπως η VLOOKUP, αλλά αναζητά στην **πρώτη γραμμή** (οριζόντια).

```
\`=HLOOKUP(A1; B1:D10; 2; 0)\`
```

### ΕΥΡΕΤΗΡΙΟ

**Σύνταξη:** `=ΕΥΡΕΤΗΡΙΟ(περιοχή; γραμμή; στήλη)`

Επιστρέφει την τιμή σε μια συγκεκριμένη θέση της περιοχής.

| **Παράμετρος** | **Περιγραφή** |
| :-: | :-: |
| `περιοχή` | Περιοχή αναζήτησης |
| `γραμμή` | Αριθμός γραμμής |
| `στήλη` | Αριθμός στήλης (προεπιλογή: 1) |


```
\`=ΕΥΡΕΤΗΡΙΟ(B1:B10; 3; 1)\`
```

### ΑΝΤΙΣΤΟΙΧΙΣΗ

**Σύνταξη:** `=ΑΝΤΙΣΤΟΙΧΙΣΗ(τιμή\\\_αναζήτησης; περιοχή\\\_αναζήτησης; τύπος\\\_αντιστοίχισης)`

Επιστρέφει τη **θέση** μιας τιμής σε μια περιοχή.

| **Τύπος αντιστοίχισης** | **Σημασία** |
| :-: | :-: |
| `0` | Ακριβής αντιστοίχιση |
| `1` | Μικρότερο που είναι μεγαλύτερο ή ίσο |
| `-1` | Μεγαλύτερο που είναι μικρότερο ή ίσο |


```
\`=ΑΝΤΙΣΤΟΙΧΙΣΗ(A1; A1:A10; 0)\`
```

### ΕΥΡΕΤΗΡΙΟ + ΑΝΤΙΣΤΟΙΧΙΣΗ

**Σύνταξη:** `=ΕΥΡΕΤΗΡΙΟ(περιοχή\\\_αποτελέσματος; ΑΝΤΙΣΤΟΙΧΙΣΗ(τιμή\\\_αναζήτησης; περιοχή\\\_αναζήτησης; 0))`

Πιο ευέλικτη εναλλακτική της VLOOKUP – μπορεί να αναζητά σε **οποιαδήποτε κατεύθυνση**.

| **Παράμετρος** | **Περιγραφή** |
| :-: | :-: |
| `περιοχή\\\_αποτελέσματος` | Στήλη με τιμές επιστροφής |
| `τιμή\\\_αναζήτησης` | Αναζητούμενη τιμή |
| `περιοχή\\\_αναζήτησης` | Στήλη στην οποία γίνεται αναζήτηση |


```
\`=ΕΥΡΕΤΗΡΙΟ(B1:B10; ΑΝΤΙΣΤΟΙΧΙΣΗ(A1; A1:A10; 0))\`
```

> **Πλεονέκτημα έναντι VLOOKUP:** Η στήλη αναζήτησης δεν χρειάζεται να είναι η πρώτη. Σταθερή ακόμα και κατά την εισαγωγή/διαγραφή στηλών.

### ΣΤΡΟΓΓΥΛΟΠΟΙΗΣΗ

**Σύνταξη:** `=ΣΤΡΟΓΓΥΛΟΠΟΙΗΣΗ(αριθμός; δεκαδικά\\\_ψηφία)`

Στρογγυλοποιεί στον καθορισμένο αριθμό δεκαδικών ψηφίων.

| **Δεκαδικά ψηφία** | **Παράδειγμα** |
| :-: | :-: |
| `2` | 3,14159 → 3,14 |
| `0` | 3,7 → 4 |
| `-1` | 34 → 30 |


```
\`=ΣΤΡΟΓΓΥΛΟΠΟΙΗΣΗ(A1; 2)\`
```

### ΣΤΡΟΓΓΥΛΟΠΟΙΗΣΗ.ΠΡΟΣ.ΤΑ.ΠΑΝΩ

**Σύνταξη:** `=ΣΤΡΟΓΓΥΛΟΠΟΙΗΣΗ.ΠΡΟΣ.ΤΑ.ΠΑΝΩ(αριθμός; δεκαδικά\\\_ψηφία)`

Στρογγυλοποιεί πάντα **προς τα πάνω** (μακριά από το μηδέν).

```
\`=ΣΤΡΟΓΓΥΛΟΠΟΙΗΣΗ.ΠΡΟΣ.ΤΑ.ΠΑΝΩ(A1; 2)\`
```

### ΣΤΡΟΓΓΥΛΟΠΟΙΗΣΗ.ΠΡΟΣ.ΤΑ.ΚΑΤΩ

**Σύνταξη:** `=ΣΤΡΟΓΓΥΛΟΠΟΙΗΣΗ.ΠΡΟΣ.ΤΑ.ΚΑΤΩ(αριθμός; δεκαδικά\\\_ψηφία)`

Στρογγυλοποιεί πάντα **προς τα κάτω** (προς το μηδέν).

```
\`=ΣΤΡΟΓΓΥΛΟΠΟΙΗΣΗ.ΠΡΟΣ.ΤΑ.ΚΑΤΩ(A1; 2)\`
```

### ΑΚΕΡΑΙΟΣ

**Σύνταξη:** `=ΑΚΕΡΑΙΟΣ(αριθμός)`

Στρογγυλοποιεί προς τα κάτω στον πλησιέστερο ακέραιο (και για αρνητικούς αριθμούς).

```
\`=ΑΚΕΡΑΙΟΣ(A1)\`
```

### ΑΠΟΚΟΠΗ

**Σύνταξη:** `=ΑΠΟΚΟΠΗ(αριθμός; δεκαδικά\\\_ψηφία)`

Αποκόπτει δεκαδικά ψηφία **χωρίς** στρογγυλοποίηση.

```
\`=ΑΠΟΚΟΠΗ(A1; 2)\`
```

### ABS

**Σύνταξη:** `=ABS(αριθμός)`

Επιστρέφει την **απόλυτη τιμή** (πάντα θετική).

```
\`=ABS(A1)\`
```

### ΥΠΟΛΟΙΠΟ

**Σύνταξη:** `=ΥΠΟΛΟΙΠΟ(αριθμός; διαιρέτης)`

Επιστρέφει το **υπόλοιπο** μιας διαίρεσης.

```
\`=ΥΠΟΛΟΙΠΟ(A1; 3)\`
```

> Παράδειγμα: `=ΥΠΟΛΟΙΠΟ(10; 3)` → `1`

### ΤΕΤΡ.ΡΙΖΑ

**Σύνταξη:** `=ΤΕΤΡ.ΡΙΖΑ(αριθμός)`

Υπολογίζει την τετραγωνική ρίζα.

```
\`=ΤΕΤΡ.ΡΙΖΑ(A1)\`
```

### ΤΥΧΑΙΟΣ

**Σύνταξη:** `=ΤΥΧΑΙΟΣ()`

Επιστρέφει έναν τυχαίο δεκαδικό αριθμό μεταξύ 0 και 1. Ενημερώνεται σε κάθε επανυπολογισμό.

```
\`=ΤΥΧΑΙΟΣ()\`
```

> Για τυχαίο αριθμό μεταξύ 1 και 100: `=ΑΚΕΡΑΙΟΣ(ΤΥΧΑΙΟΣ()\\\*100)+1`

## Απόλυτες αναφορές

Στο πρόγραμμα η λειτουργία αναφοράς μπορεί να επιλεγεί από αναπτυσσόμενο μενού:

| **Λειτουργία** | **Παράδειγμα** | **Σημασία** |
| :-: | :-: | :-: |
| Σχετική | `A1` | Μετατοπίζεται κατά την αντιγραφή |
| Σταθερή στήλη | `$A1` | Η στήλη παραμένει, η γραμμή μετατοπίζεται |
| Σταθερή γραμμή | `A$1` | Η γραμμή παραμένει, η στήλη μετατοπίζεται |
| Απόλυτη | `$A$1` | Παραμένει πάντα η ίδια κατά την αντιγραφή |


## Συντομεύσεις πληκτρολογίου

| **Συντόμευση** | **Λειτουργία** |
| :-: | :-: |
| `Ctrl+S` | Αποθήκευση τύπου στα αγαπημένα |
| `Ctrl+C` | Αντιγραφή τύπου |
| `Ctrl+Z` | Αναίρεση |
| `Ctrl+Y` | Επανάληψη |
| `Ctrl+F12` | Ελαχιστοποίηση / επαναφορά παραθύρου |
| `Del` | Διαγραφή αγαπημένου (στη λίστα) |
